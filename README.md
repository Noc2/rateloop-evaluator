# RateLoop Evaluator

An Apache-2.0 local evaluator for explicit rating questions, built around GLiNER2.5 multilingual.
It runs independently of a RateLoop account. Customer examples and private adaptations are never public by default.

Implementation is in progress. Supported commands, verification evidence and deployment instructions are added with
their corresponding tested components. No customer data or production model-quality claim is included in this repository.
